ASTUCE 1 — LOGIQUE

Équivalence et négation

(p ⇔ q) ⇔ [(p ⇒ q) et (q ⇒ p)]
¬(p ⇔ q) ⇔ [¬(p ⇒ q) ou ¬(q ⇒ p)]
⇔ [¬(¬p ou q) ou ¬(¬q ou p)]
⇔ (p et ¬q) ou (q et ¬p)
ASTUCE 2 — PARTIE ENTIÈRE

Définition

(∀x ∈ ℝ)(∃!p ∈ ℤ) : p ≤ x < p + 1

p est appelé la partie entière de x, notée :

[x] ; E(x) ; ⌊x⌋
[x] = p ⇔ p ≤ x < p + 1
[x] ≤ x < [x] + 1
x ─────────→ [x] = p
ASTUCE 3

Implication

Si p alors q ⇔ p ⇒ q
p ssi q ⇔ p ⇔ q
ASTUCE 4

Négation d'un encadrement

¬(a ≤ x ≤ b)
⇔ (x < a ou x > b)
ALGÈBRE — ASTUCES DU CAHIER

Somme, différence et factorisation

(x − y) + (x + y) = 2x
(x + y) − (x − y) = 2y
x² − y² = (x − y)(x + y)
x³ − y³ = (x − y)(x² + xy + y²)
x³ + y³ = (x + y)(x² − xy + y²)
ALGÈBRE — ASTUCE 2

Identité avec trois nombres

(b − a)² + (a − c)² + (b − c)²
= 2(a² + b² + c² − ab − ac − bc)
a² + b² + c² ≥ ab + ac + bc

Cube d'une différence

ASTUCE 2

Cube d'une somme
